# 综述逻辑与骨架

在需要比较多篇文献、设计段落顺序或把矩阵转为正文时读取。

## 一、六类常用关系

### 1. 因果或机制链

结构：`A → B → C`。

只有当来源分别支持相邻节点，或同一研究检验完整链条时使用。若文献甲发现 A 影响 B，文献乙发现 B 影响 C，应写成“综合现有证据可以形成……的解释路径”，不能冒充某篇文献已经检验 A 对 C 的完整机制。

### 2. 并列机制

结构：`A → B` 与 `A → C`。

适合组织同一政策或冲击的多条渠道。并列项必须处于相同分析层级，不把结果、机制和条件混为一组。

### 3. 研究演进

结构：`早期界定问题 → 后续改进方法/扩展对象 → 最新研究检验边界`。

时间顺序只有在知识确实发生推进时才有意义。不能仅按发表年份排列。

### 4. 共识与争议

先写共同判断，再定位分歧来自理论假设、样本、时期、变量度量或识别方法。不要用“结论不一致”结束，需说明不一致发生在哪里。

### 5. 边界与异质性

围绕地区、行业、所有制、发展阶段、制度背景或冲击强度组织。注意“一组显著、另一组不显著”不自动证明组间系数存在显著差异。

### 6. 上游与下游结果

一篇文献的结果可能是另一篇文献的解释变量。例如金融支持、技术吸收、创新与出口绩效可以形成研究脉络，但必须逐段核验方向和主体是否一致。

## 二、段落骨架

推荐先写骨架，不先追求句子美观：

1. **主题句**：本段要回答的一个具体问题。
2. **共同证据**：合并结论相近的研究，说明共识。
3. **关系展开**：解释机制、演进或方法差异。
4. **反例或边界**：指出结论在哪些情境下改变。
5. **接口句**：把本段结论引向下一问题或真实研究缺口。

每个骨架节点至少绑定一个来源 ID。没有来源的节点标记 `[证据缺口]`，不要直接扩写。

## 三、作者信息的使用

可使用作者—年份的情形：界定概念或理论来源；呈现关键方法变化；对立观点需要明确责任主体；句间承接需要清楚的指代。

不宜使用的情形：连续多句均以作者姓名开头；作者只是引文编号的重复表达；删除作者后，主题与证据关系仍然清楚。

## 四、从综述引出研究缺口

研究缺口必须由矩阵比较得到，可来自：对象或地区覆盖不足；关键机制只有理论推断；既有测量无法区分某种结果；识别策略无法处理特定偏误；不同情境结论冲突且原因未明；已有研究集中于上游结果，尚未连接到目标结果。

避免仅凭文献数量少就宣布“空白”。缺口句应说明“已有研究完成了什么，但尚不足以回答什么”。
