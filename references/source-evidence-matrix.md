# 文献证据矩阵

在 `digest`、`map` 和 `synthesize` 模式中读取。矩阵是后续关系判断的依据，不是最终综述的固定展示形式。

## 必要字段

| 字段 | 记录要求 |
|---|---|
| 来源 ID | 为每篇文献设置稳定编号；不要在写作过程中反复变更 |
| 书目信息 | 作者、年份、题名、期刊或来源、DOI/URL（如有） |
| 获取路径 | 用户提供、关键词检索、后向追溯、前向追踪或定向补检；检索来源与轮次 |
| 证据层级 | 全文、摘要、题录或二手转述 |
| 研究目的 | 作者真正回答的问题，不复制宽泛背景 |
| 研究对象 | 国家、地区、行业、企业、个体或制度情境 |
| 数据与样本 | 时段、样本量、数据来源及层级；原文未报告则写“未见” |
| 研究方法 | 理论、案例、调查、计量或实验方法；保留具体模型名称 |
| 核心结论 | 方向、条件、显著性和作用对象，不提高因果强度 |
| 机制与边界 | 作者直接检验的渠道、异质性、适用条件和局限 |
| 理论贡献 | 作者声明且由研究支撑的贡献，不代作者拔高 |
| 当前用途 | 支持背景、概念、机制、争议、边界、方法或研究缺口 |
| 目的贡献 | 该来源能够怎样直接回答本次综述问题；无法直接回答时写“无” |
| 正文最小命题 | 若纳入正文，以“因素—核心机制—结果方向”写出一条不可替代的信息 |
| 机制证据等级 | 直接检验、间接证据、理论推断或未检验；决定使用“通过”还是“可能通过” |
| 矩阵保留信息 | 已核验但与当前目的无直接关系的方法、机制、异质性或其他结果 |
| 候选主题组 | 该来源最适合进入的研究方面；无法归组时说明原因 |
| 增量贡献 | 相较同组来源新增了什么机制、对象、方法、争议或边界 |
| 纳入状态 | `CORE`、`SUPPORT` 或 `EXCLUDE` |
| 取舍理由 | 保留、合并或剔除的具体学术理由 |
| 来源定位 | 页码、章节、表图、原文片段或摘要句，便于回查 |

## 提取规则

1. 同一篇文献存在多个结论时拆成多条命题，不把整篇文章压成一句泛化结论。
2. 区分作者的理论推断、实证结果和政策解释；三者不能相互替代。
3. 报告“显著”时记录统计对象和方向。没有显著性信息时不要补写。
4. 机制变量显著变化不自动等于完整中介链成立。
5. 只读到摘要时，研究方法和贡献只能按摘要明示内容填写。
6. 文献与当前主题仅有关键词重合但无法支持具体命题时，标记为“背景候选”，不要强行写入正文。
7. 不预设用户提供的来源必须全部进入正文；正文取舍以主题相关性、证据质量、增量贡献和逻辑适配度为准。
8. 负向、不显著或冲突结论不能因影响叙事流畅而被排除，应优先检查其是否构成真实争议或边界。
9. 矩阵可以完整，正文必须克制。提取到一项信息不等于需要写出；只有“正文最小命题”可以直接进入骨架，其余字段用于核验和备查。
10. “正文最小命题”必须回到目的契约。若删去该命题不会改变读者对综述问题的回答，将其降为矩阵保留信息。
11. 效应型综述的正文最小命题不得只剩“X促进或抑制Y”。从作者报告的多个机制中选择一条最核心的短链；能够由一个上位概念准确涵盖时先概括，无法涵盖时默认保留一项，必要时最多保留两项紧密相关的机制。
12. 机制强度服从证据等级。直接中介或渠道检验可以写“通过”；仅有理论分析、相关证据或作者讨论时降低为“可能通过”或“被认为”；没有来源支撑时不得补造机制。
13. 系统检索任务必须保留获取路径和筛选轮次，使每篇来源能够回溯到种子检索、前后向引文扩展或定向补检。

## 比较列

矩阵完成后增加跨文献比较标签：

- `AGREE`：对同一命题方向一致；
- `CONFLICT`：结论相反或证据不一致；
- `EXTEND`：扩展对象、时期、方法或结果变量；
- `CHAIN`：分别支撑同一机制链的相邻节点；
- `BOUNDARY`：给出条件、异质性或外部效度限制；
- `METHOD`：方法改进、识别差异或测量变化；
- `UNRELATED`：与综述问题没有足够关系。

标签用于辅助组织，不能代替对具体关系的文字说明。

## 命题证据状态表

关系标签描述两篇或多篇文献之间的关系；证据状态描述整个纳入文献集对某一命题能够支持到什么程度。完成跨文献比较后，另建命题表，至少记录：核心命题、支持来源、可靠反例、来源独立性与可比性、`CONSENSUS` / `DISAGREEMENT` / `INSUFFICIENT` 状态、`BOUNDARY` 限定和正文允许使用的表述强度。具体标准见 [系统检索与证据状态](systematic-retrieval-and-evidence-status.md)。
