# 文献筛选、分组与补检

在用户提供文献较多、研究结果跨越多个领域、正文出现强行串联，或某一主题证据明显不足时读取。目标不是减少阅读量，而是提高进入正文的每篇文献的边际贡献，并决定采用单轴还是分组叙事。

## 一、先评价来源，不预设全部纳入

为每篇来源增加五项判断：

| 判断项 | 核心问题 |
|---|---|
| 目的贡献 | 它是否直接改变读者对综述问题的回答，而非只是提供更多论文细节 |
| 主题相关性 | 是否直接回答当前综述问题，而非仅共享关键词 |
| 证据质量 | 是否有可核验全文或摘要，方法和结论强度是否清楚 |
| 增量贡献 | 相较同组来源，是否增加新机制、结果、对象、方法、争议或边界 |
| 逻辑适配度 | 能否进入某一主题组的中心判断，而无需补造因果桥 |

据此标记：

- `CORE`：直接完成目的契约，构成中心判断、必要争议或结论边界的证据；若综述问题本身关注机制，关键机制也可列为核心；
- `SUPPORT`：与核心来源结论相近，可用于合并引注、外部效度或方法对照；
- `EXCLUDE`：偏离主题、证据过弱、与更强来源高度同质，或进入正文会迫使主线转向。

删除的是正文席位，不是文献本身。被排除来源仍保留在证据矩阵，便于用户回查。

来源本身高度相关，不代表其中所有结果都相关。入选以“正文最小命题”为单位，而不是以整篇文章为单位；同一篇文献可以用一条核心机制解释其结论，其余机制、方法和异质性继续留在矩阵。

## 二、允许删除，但必须有学术理由

可从正文剔除以下来源：

- 仅与主题共享背景词，不能支持具体命题；
- 与已有高质量来源在对象、结论和机制上高度同质，没有新增边界；
- 研究结果属于另一独立领域，纳入后需要新增整条主轴；
- 证据层级不足，而同一命题已有可核验的更强来源；
- 只能依靠未经检验的因果关系才能与相邻文献连接。
- 主要结论已经进入正文，但其余发现不能改变对综述问题的回答。

不得因以下原因删除：结论为负或不显著；与主流观点冲突；样本地区不同但恰好构成外部效度边界；方法差异能够解释争议。可靠的反例和冲突证据优先进入“争议/边界”位置。

如果用户明确要求覆盖全部来源，仍需指出哪些文献重复或偏离，并通过附表、脚注或压缩合并满足覆盖要求，不能假装它们同属一条链。

## 三、决定单轴还是分组

优先尝试用 3—5 个节点复述材料。出现以下任一情况时考虑分组：

- 结果变量分属三个及以上独立领域，如创新、就业、环境与安全；
- 主体层级频繁切换，且前一层结果不是后一层的已检验机制；
- 交换主题块的顺序不影响经济含义，说明它们本质上是并列研究线；
- 为容纳全部来源，正文必须反复使用空泛过渡句或未经支持的因果桥；
- 某一主题来源过度集中，掩盖了其他与综述问题同等重要的研究线。

分组数量通常控制在 2—4 个。分组标准应来自研究问题，可按结果领域、机制、主体层级、争议或研究演进划分；不能仅按作者、年份或文献数量平均切块。

每个主题组应当：

1. 回答一个明确问题；
2. 拥有一个中心判断和一条组内主轴；
3. 优先由至少两篇相互独立的直接来源支撑；
4. 呈现完成目的契约所需的结论，并为重要效应保留一条核心机制；完整机制清单、边界或争议按需进入，不作为每组固定配置。

组与组之间使用分类、比较或范围扩展关系。只有来源直接检验跨组传导时，才能将两个主题组写成因果链。

## 四、证据不足时定向补检

以下情况可以主动检索新增文献：

- 某一重要主题仅有一篇直接来源，难以判断其结论是否稳健；
- 现有来源只有题录、二手转述或宽泛背景，缺少可核验的直接证据；
- 组内全是同方向结论，需要查找真实的边界、异质性或反例；
- 用户材料过度集中于一个结果领域，导致综述无法覆盖已经确定的关键研究线；
- 相邻命题之间确实缺少事实或机制节点，且缩小论断仍无法解决。

检索必须围绕明确的缺失节点，优先使用同行评议的原始论文、正式期刊页面和权威学术数据库。新增来源应核验作者、年份、题名、研究对象、方法和结论强度，并单独说明其补充了哪个主题或接口。

不得为了组间篇数对称而补文献，也不得用一般性背景研究冒充政策效应证据。若检索后仍不足，应合并或删除证据薄弱的主题，而不是夸大结论。

## 五、发挥创新与批判判断

创新不是自由补造机制，而是重新定义更有解释力的问题和分组方式。允许：

- 质疑用户最初的分类是否把结果、机制和条件混在一起；
- 从证据中提出更合适的主题轴，并解释为什么；
- 识别被大量同质文献掩盖的反例、边界或研究层级差异；
- 用更强的新来源替换弱来源，或用一条合并引注替代多条重复描述；
- 放弃无法成立的完整故事，改写为多个边界清楚的研究方面。

批判判断必须透明。交付时简要说明保留、剔除和新增了哪些来源以及理由；用户只要正文时可压缩披露，但不得隐瞒实质性取舍。

## 六、成稿检查

- 每句话是否直接帮助回答目的契约？准确但无关的论文细节是否已经退回矩阵？
- 每项重要影响因素是否既说明了方向，也用一条简洁机制回答了“为什么”？
- 相同结果是否区分了不同因素的核心渠道，而不是用“也”“类似”草率合并？
- 每个主题组是否可以用一句中心判断概括？
- 每篇进入正文的来源是否带来独立贡献？
- 删除任一来源后，是否会改变对综述问题的回答、必要边界或真实争议？若不会，考虑合并或剔除。
- 组内句序是否由内容决定，组间是否明确属于分类而非因果？
- 新增来源是否直接补足缺口，而非引入新的旁支？
- 被剔除文献是否保留了可回查的理由，可靠反例是否得到公平处理？
