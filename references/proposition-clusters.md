# 命题簇与软衔接

在整合 3 篇以上文献、压缩综述、生成单段综述或审查“衔接生硬”问题时读取。本规则补充原有证据矩阵、逻辑骨架和引文保真要求，不降低证据标准。

## 一、从来源卡片改为命题簇

不要把“文献 A、文献 B、文献 C”直接转换为三个句子。先拆出各文献能够支持的原子命题，再按共同问题合并：

| 命题簇 | 典型功能 |
|---|---|
| 直接效应 | 回答核心变量是否影响目标结果 |
| 上游条件 | 成本、信息、融资、可达性、制度或网络变化 |
| 主体反应 | 企业进入、投资、创新、产品调整或风险分散 |
| 下游结果 | 规模、质量、生产率、韧性或福利变化 |
| 边界与争议 | 地区、行业、主体、时期、测量或方法造成的差异 |

同一篇文献可以在矩阵中拥有多条命题，但进入一段正文时只选择最能回答目的契约的一条。所谓“服务主线”不是展示该文献最有特色的机制，而是提供当前综述不可缺少的答案。支持相同命题的来源应共同置于一句话末尾，不逐篇复述。

## 二、先决定单轴还是分组

先尝试用一条 3—5 节点主线复述材料，例如：

`基础设施改善 → 市场可达性提高 → 要素重新配置 → 出口升级 → 韧性增强`

如果来源能够共享同一问题和相邻机制，使用单轴并允许一条最终汇合的辅助证据线。不得在“国家—城市—企业”“规模—质量—韧性”“地区—行业—距离”等分类轴之间来回切换。

如果材料跨越多个独立结果领域或主体层级，且不存在经过检验的跨领域传导关系，先读取 [文献筛选、分组与补检](source-selection-grouping.md)，剔除低增量来源后分为 2—4 个主题组。每组各自维持一条主轴；组间用分类或比较连接，不强求前一组成为后一组的原因。

## 三、相邻句依赖只在组内成立

同一主题组内的相邻句之间至少满足一种关系：

- 前句结果成为后句原因；
- 后句解释前句机制；
- 后句将前句结论推进到下游结果；
- 后句限定前句成立的条件；
- 后句用相反证据修正前句；
- 两条证据线在后句汇合为待研究问题。

优先使用带经济含义的接口：运输成本下降扩大出口，但不必然改善质量；市场扩大形成竞争压力，竞争又改变创新投入；创新提高常态绩效，也可能改善冲击下的适应能力。不得仅用“此外”“进一步”“沿着这一逻辑”等词模拟关系。

主题组之间不执行上述依赖规则。进入下一组时，可以直接使用分类标记或新的中心主语重新起笔，不需要把上一组的结果改写成下一组的原因，也不需要让前一组末句预埋下一组概念。组间若无直接传导证据，禁止使用“在此基础上”“由此进一步”“进而影响”等暗示机制递进的表达。

## 四、信息取舍

证据矩阵保存完整书目信息、样本、方法、系数、稳健性和异质性。正文默认删除以下内容：

- 对主线没有解释力的样本量和年份；
- 不构成实质差异的精确系数；
- 常规稳健性检验清单；
- 一篇文献的全部机制与全部异质性；
- 只用于证明“读过文献”的方法细节。

只有当这些信息解释争议、识别边界或直接导出研究缺口时才保留。

先执行目的测试，再执行主线测试。某项内容即使能够和前后句顺畅连接，只要不能帮助回答综述问题，就不得因为“逻辑通顺”而保留。对于“影响因素研究现状”这类效应型综述，正文通常需要交代因素类别、影响方向和一条能够回答“为什么”的核心机制；门槛条件、完整异质性、识别细节及其余机制默认留在矩阵。对于机制型或方法型综述，则按目的契约相应调整，不能机械套用这一删减范围。

核心机制采用最小解释链：`因素 → 关键渠道 → 结果`。一篇文献报告多个渠道时，先判断能否用来源支持的上位概念概括；不能概括时，选择证据最强且最贴近综述问题的一项，确有必要时保留两项紧密相关的机制。不得把机制压缩成没有解释力的“发挥促进作用”，也不得把全部渠道并列抄入正文。

不同因素得到相同结果时，不能只写“同样提高”“也具有促进作用”或“表现出类似效果”。应在证据允许范围内说明作用渠道的不同，例如一项因素从融资端发挥作用，另一项因素通过知识扩散提高效率。该比较用于区分机制，不代表两项因素之间存在因果关系。

正文也不承担“展示全部文献”的功能。与更强来源高度同质、偏离组内问题或需要虚构逻辑桥才能纳入的文献，应移回证据矩阵并说明取舍理由；可靠的反例和冲突证据不得因此删除。

## 五、作者与引文

- 以经济变量、行为主体和约束条件作为默认主语。
- 作者—年份按功能使用：适用于概念来源、关键转折、争议归属、方法创新，以及同组内直接切换因素或分析视角会显得突兀的情况。
- 叙述式引文必须与关系说明共同出现。姓名标记观点责任，“从另一层面看”“与上述结论不同”等内容说明其与上文的关系；作者姓名本身不是过渡逻辑。
- 多篇文献共同支撑同一命题时，优先合并为主题句并集中引注，不逐个点名。
- 连续两句以上使用“作者（年份）发现……”时，检查是否已经退化为来源卡片排列；除真实争议对举外，应合并或改回主题主语。
- 同一来源在同一段中默认只引用一次。
- 连续三句均为“一个句子对应一个来源”时，视为引文孤岛风险；优先合并共同命题。
- “每篇最多两句话”是上限，不是配额，不得因此给每篇文献单独造句。

## 六、单段模板

用户要求单段且材料适合单轴时，优先使用最小模板：

`中心判断 → 影响方向与核心机制 → 必要的结论修正或边界 → 研究不足`

效应型综述默认使用一条最小解释链，但不展开全部机制。只有目的契约明确要求系统解释机制或研究演进时，才扩展为更长的机制链或演进链；不得仅因原论文报告了多个机制就自动增加节点。

材料需要分组时，改用：

`范围概括与分类标准 → 主题组一的内部主线 ‖ 主题组二的内部主线 ‖ 主题组三的内部主线 → 可选的范围性总评或研究不足`

符号“‖”表示逻辑链在主题边界处停止并重新开始，不表示因果、递进或研究演进。单段也可使用“其一、其二、其三”标明分类。分类词只负责提示主题边界，不能把不同主题伪装为因果递进。跨组总评不是必需项；如果总评只能把三组机制重新罗列一遍，直接删除。文献数量只是压缩提示；无论数量多少，都不把低增量或偏离主题的来源强塞入正文。

## 七、研究缺口

优先采用交叉式缺口：文献线一已经说明 A 影响 B，文献线二已经说明 B 与 C 有关，但特定情境下 A 对 C 的作用仍未被直接检验。也可以从结论冲突、地区外部效度、测量局限或识别偏误推出缺口。

仅凭“文献数量少”不能宣布空白。缺口中的研究对象、机制和边界词必须在前文出现并完成比较。

## 八、成稿初审

1. **换序测试**：交换相邻句仍不影响理解，说明句序可能只是罗列。
2. **去连接词测试**：删除空泛连接词后关系消失，说明没有真实接口。
3. **去作者测试**：删除作者姓名仍不影响归因时，改用命题作主语。
4. **引文聚类测试**：连续三个单来源句应重新检查能否合并。
5. **主线复述测试**：无法用 3—5 个节点概括时，说明组织轴过多。
6. **缺口回溯测试**：结尾的新概念必须能回到前文证据。
7. **证据边界测试**：分别标记直接发现、综合解释和理论推演，不混用强度。
8. **分组必要性测试**：若全文无法由一条 3—5 节点主线复述，检查是否应当分组，而不是继续增加过渡句。
9. **来源必要性测试**：每篇正文来源是否增加了独立机制、边界、争议或外部效度；没有增量时合并或剔除。
10. **跨组因果测试**：主题组之间是否只有分类关系，却被写成“进一步”“由此”等因果递进；若是，重写分组句和接口。
11. **跨组停链测试**：每个主题组结束后能否自然停住；若必须借上一组末句才能引出下一组，检查是否误把分类关系写成故事线。
12. **并列负荷测试**：一句是否包含三个以上同层级机制、结果或条件，或连续两句使用多项并列骨架；若是，保留中心项，将其他内容改为条件、边界或移回矩阵。
13. **目的贡献测试**：遮住作者与引文后，每句话是否仍在回答综述问题；若只是在完整介绍某篇论文的机制、方法或异质性，移回矩阵。
14. **最小充分测试**：删去一句后，读者对因素、方向、必要边界或研究缺口的理解是否变化；若不变化，删除该句。
15. **作者功能测试**：删除作者—年份后，视角切换或观点责任是否仍然清楚；若清楚则删去姓名，若不清楚则保留，并确认它没有被用来掩盖逻辑断层。
16. **机制空壳测试**：每项重要影响因素是否只剩“促进、抑制、具有作用”等方向词；若是，从来源中补入一条最核心机制。
17. **机制过载测试**：同一句是否并列三个以上渠道，或连续介绍同一论文的全部机制；若是，使用上位概念概括，或保留最强的一至两项。
18. **同效异机测试**：两个因素产生相同结果时，是否只用“也”“同样”“类似”衔接；若是，改写为不同核心机制的比较。

完成上述初审后，继续执行 [成稿后逐句复审](post-draft-audit.md)。不得因段落已通过主线复述测试而省略相邻句逐对审查。

逻辑骨架通过后还不等于中文表达自然。继续执行 [自然学术衔接](natural-academic-flow.md)，将关系标签藏回经济主体的动作中，避免把命题簇的排列过程直接写成正文。
